# 🏡 BronlaDacha

BronlaDacha — O'zbekiston bo'ylab dachalarni qidirish va bron qilish uchun yaratilayotgan professional Telegram bot.

## Asosiy imkoniyatlar

- 🏡 Dacha qidirish
- 📍 Viloyat va tuman bo'yicha qidiruv
- 📅 Bron qilish
- 👤 Foydalanuvchi profili
- 🏠 Dacha egasi paneli
- 👑 Admin paneli
- ⭐ Reyting va sharhlar
- ❤️ Sevimlilar
- 💳 To'lov tizimi
- 📊 Statistika
